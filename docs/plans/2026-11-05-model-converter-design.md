# 模型转换工具
面向 Shapr3D，支持 3MF / STL / STEP 六个转换方向。毫米为内部单位，STL 需用户指定单位。网格转 STEP 必须检查闭合、方向和实体有效性；无法重建的模型明确失败，不宣称恢复参数化特征。STEP 转网格支持精度设置。

网页提供文件选择、输出格式、单位、精度、任务状态和下载。浏览器执行 3MF 与 STL 转换；CAD 容器执行 STEP 路径，异步任务避免长 HTTP 请求。Workers 承载静态资源、口令校验和任务路由。首次部署为私人使用，容器数限制为 1。

第一版结果保留在容器临时磁盘一小时，重启会清除；无需 R2 账号开通和持久存储。页面明确此限制。后续如需历史记录，再接 R2。

验证：六方向功能测试、开放网格拒绝、3MF 组件变换及单位、超限和异常输入、前端构建和类型检查、真实坐姿矫正模型转换与 CAD 回读。Shapr3D 实测需另行完成。
